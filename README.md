# Аналіз та підготовка даних: NYC TLC Yellow Taxi Trip Records

Цей репозиторій містить матеріали та відтворюваний пайплан для другого домашнього завдання з курсу **Relational Databases for DS** у [GoIT Neoversity](https://www.edu.goit.global/learn/47501230/52381036/53719777/homework). Проєкт охоплює повний цикл інженерії даних: завантаження сирого публічного датасету, створення буферної та фінальної типізованої таблиці у PostgreSQL, проведення аудиту якості та аналітичних EDA-запитів.

---

## 📋 Опис датасету

* **Назва датасету:** NYC TLC Yellow Taxi Trip Records (вибірка за січень 2024 року)
* **Офіційне джерело:** [NYC Taxi & Limousine Commission (TLC) Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)
* **Формат джерела:** Parquet (конвертовано у контрольований CSV для завантаження)
* **Обсяг вибірки:** **99 999 рядків** (контрольована підмножина для демонстрації повного циклу перевірок)

---

## ⚙️ Спосіб формування вибірки

1. Завантаження офіційного місячного Parquet-файлу з хмарного сховища NYC TLC за допомогою Python-скрипта (`urlretrieve`).
2. Фільтрація та збереження лише необхідних колонок, що критично важливі для бізнес-логіки та аналізу поїздок (зокрема ідентифікатори вендора, час посадки/висадки, кількість пасажирів, дистанція та суми тарифів).
3. Формування контрольованої вибірки обсягом **100 000 рядків** за допомогою методу `.head(100_000)` у бібліотеці `pandas`.
4. Експорт підмножини у локальний файл `hw3_taxi_sample.csv` для подальшого швидкого імпорту через `COPY FROM STDIN` у PostgreSQL.

---

## 🛠️ Архітектура та структура бази даних

Пайплан виконання реалізовано у середовищі **Google Colab** з використанням локального сервера PostgreSQL (`pgserver`):
1. **Staging-рівень (`hw3_taxi_staging`):** Усі колонки завантажені як `TEXT` для запобігання помилкам парсингу через пропуски чи спеціальні маркери.
2. **Clean/Final-рівень (`hw3_taxi_trips`):** Типізована таблиця з суворими обмеженнями (`PRIMARY KEY`, `NOT NULL`, сутнісні `CHECK`-обмеження на невід'ємну відстань та коректну хронологію поїздки).

1. Клонуйте репозиторій або завантажте Jupyter Notebook із цього репозиторію.
